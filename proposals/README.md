# Feature and functional proposals for Sheriff

## Suggesting a Proposal 

1. Fork the repo

2. In your fork, create a `markdown` file such as `isolated-workspace-proposal.md` that would contain the proposal information. 

3. Keep proposals organized; Include an overview and actual sections related to the proposal. Include examples if any. 

4. Keep your proposal not too long; Under 300 lines

5. Create an issue in the original repo to point it to the proposal(optional but recommended for faster alerts)
